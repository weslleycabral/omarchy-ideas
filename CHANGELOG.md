## [1.0.0] - 2026-10-23

### Added

- Lightbulb widget in the bar: left-click opens the list of ideas, right-click adds a new one.
- Dialog with three views: new idea, list of titles and single idea (copy and delete).
- Spelling fixes and titles from the first AI agent CLI that answers: Claude Code, Codex, Gemini CLI or OpenCode.
- Interface in English, Portuguese, Spanish and French, set with `ideas lang`.
- `ideas` command: `new`, `list`, `open`, `add`, `rm`, `process`, `lang`, `json`.
